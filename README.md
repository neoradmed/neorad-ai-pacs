# NeoRad AI PACS Viewer

A custom OHIF-based PACS viewer with integrated AI capabilities for medical imaging, including specialized support for oncology workflows.

## 📁 Repository Structure

```
/extensions/neorad-ai       ← Custom AI extension
/modes/neorad-oncology      ← Oncology workflow mode  
/platform/app               ← OHIF core integration
/docs                       ← Documentation, notes & prompts
README.md                   ← This file
```

## 🚀 Features

- **AI-Powered Analysis** - Custom AI extension for intelligent image analysis
- **Oncology Mode** - Specialized workflow optimized for oncology cases
- **OHIF Integration** - Built on top of the OHIF viewer platform
- **Extensible Architecture** - Modular design for easy customization

## 🔧 Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/neoradmed/neorad-ai-pacs.git
cd neorad-ai-pacs
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Start development server
```bash
npm start
# or
yarn start
```
